# Angela Learning Engine — Grade 3 FAST practice

This is a separate Grade 3 learning path in the A. L. S. Tutor GitHub Pages site. It provides short, original practice for Florida FAST Grade 3 ELA Reading and Mathematics while ALE's Supabase project is inactive.

## Student experience

- A seven-question starting check samples all three Reading and all four Math reporting areas. It recommends a next lesson; it is not a grade or a measure of mastery.
- Each skill page gives a brief goal, a worked example, and three explicit thinking steps.
- A skill check has three questions. A wrong answer receives a gentle clue and another try; after a second miss, the tutor explains the answer and reasoning.
- The optional mixed check has ten original items, five per subject. There is no timer.
- Progress is stored in local browser storage on that device only. No name, school, email, student chat, or AI provider is collected.
- The tutor shows practice evidence and never predicts a FAST score or promises a proficiency result.

## Skill map

| Subject | Florida FAST reporting category | Practice scope |
|---|---|---|
| Reading | Reading Prose and Poetry | Literary details, theme, inference, narrator, poetry, and figurative language |
| Reading | Reading Informational Text | Central idea, text structure/features, author purpose, perspective, and supporting reasons |
| Reading | Reading Across Genres & Vocabulary | Context clues, morphology, figurative language, summarizing, and comparing texts |
| Math | Number Sense and Additive Reasoning | Place value, comparing, rounding, addition, subtraction, and word problems |
| Math | Number Sense and Multiplicative Reasoning | Equal groups, arrays, multiplication, division, and story problems |
| Math | Fractional Reasoning | Equal parts, fraction models, number lines, and comparing fractions |
| Math | Geometric Reasoning, Measurement, and Data Analysis and Probability | Shapes, area, perimeter, time, measurement, and data displays |

The math category balance follows the Florida Grade 3 blueprint's four reporting categories. Each is listed at 23–29% of the state assessment. The Reading mix uses the three published reporting categories. The tutor's short checks are learning activities; they do not reproduce the length, adaptive scoring, or secure items of the state test.
